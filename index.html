Labs interactifs

Retrouvez ici l'ensemble des exercices ludiques du programme, classés par module. Chaque lab fonctionne sur téléphone, sans installation — il suffit de scanner le QR code partagé par votre formateur.

Cette page et l'ensemble des labs sont hébergés gratuitement sur GitHub Pages.
Les réponses des participants sont stockées de façon anonymisée dans une base Firebase dédiée à ce programme.
